Возвращение Супермена

Superman Returns

Мировая премьера: 28 июня 2006

Слоган: Посмотрите на небо.

Сюжет: После пятилетнего отсутствия Супермен возвращается на Землю. Пока он искал остатки своей родной планеты, многое успело измениться. Мир привык жить без него. У Лоис Лэйн есть жених, она родила сына и получила Пулитцеровскую премию за статью "Почему миру не нужен Супермен". А Лекс Лютор вынашивает планы по уничтожению миллиардов людей.
