Исходный Код

Source Code

Мировая премьера: 1 апреля 2011

Слоган: Используй каждую секунду.

Сюжет: Капитан Колтер Стивенс получает задание установить личность террориста, взорвавшего поезд всего несколько часов назад и планирующего устроить ещё более мощный взрыв в центре Чикаго, который может унести тысячи жизней. Секретная экспериментальная программа "Исходный код" позволяет Колтеру на короткое время оказаться в теле одного из пассажиров обречённого поезда. Каждый раз, возвращаясь в прошлое, он получает всего восемь минут, чтобы вычислить террориста. Но чем больше Колтер узнаёт, тем сильнее убеждается, что способен предотвратить взрыв поезда.
